# Semaine 7, Jour 5 : Les Questions

## Objectif du jour
Poser toutes sortes de questions.

## Mots Interrogatifs
*   **Onde** : Où
*   **Quando** : Quand
*   **Quem** : Qui
*   **Como** : Comment
*   **Por que** : Pourquoi
*   **Quanto** : Combien (prix/quantité)

## Exemples
*   *Quanto custa?* (Combien ça coûte ?)
*   *Quem é você?*
*   *Quando você chega?*

## Pratique du jour (30% - Questions)
1.  (Où) ________ você mora?
2.  (Quand) ________ é o seu aniversário?
3.  (Combien) ________ custa a água?
4.  (Qui) ________ é ela?
