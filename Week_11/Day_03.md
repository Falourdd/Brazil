# Semaine 11, Jour 3 : Passé vs Imparfait

## Le duel
*   **Pretérito Perfeito (Passé Composé/Simple)** : Action ponctuelle, finie.
    *   *Eu comi uma maçã.* (J'ai mangé une pomme - Une fois).
*   **Pretérito Imperfeito (Imparfait)** : Habitude, durée.
    *   *Eu comia maçã todo dia.* (Je mangeais des pommes tous les jours).

## Contexte
Souvent, on utilise les deux ensemble :
*   *Eu **dormia** (Imparfait - action en cours) quando o telefone **tocou** (Passé - interruption).*
    (Je dormais quand le téléphone a sonné).

## Pratique du jour (30% - Passé vs Imparfait)
1.  Hier, j'ai étudié 1 heure. -> Ontem, eu ________ 1 hora.
2.  Quand j'étais petit, j'étudiais le piano. -> Quando eu era pequeno, eu ________ piano.
3.  Je dormais quand il est arrivé. -> Eu ________ quando ele chegou.
