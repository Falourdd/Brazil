# Semaine 1, Jour 2 : Se Présenter (Verbe Ser)

## Objectif du jour
Savoir dire qui vous êtes (nom, identité) en utilisant le verbe fondamental **Ser** (Être).

## Vocabulaire
*   **Nome** : Nom
*   **Prazer** : Enchanté
*   **Senhor / Senhora** : Monsieur / Madame

## Grammaire : Verbe SER (Présent)
Le verbe *Ser* est utilisé pour les caractéristiques permanentes ou essentielles (identité, origine, profession).

| Portugais | Français |
| :--- | :--- |
| **Eu sou** | Je suis |
| **Você é** | Tu es / Vous êtes (singulier) |
| **Ele / Ela é** | Il / Elle est |
| Nós somos | Nous sommes |
| Eles / Elas são | Ils / Elles sont |

*> Note : "Você" est le pronom utilisé pour "Tu" dans la majeure partie du Brésil, mais il se conjugue comme la 3ème personne (comme "il/elle").*

## Modèles de phrases
*   **Qual é o seu nome?** (Quel est votre nom ?)
*   **Meu nome é [Prénom].** (Mon nom est...)
*   **Eu sou o [Prénom].** (Je suis [Prénom].)
*   **Muito prazer.** (Enchanté.)
