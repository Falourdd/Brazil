# Semaine 1, Jour 3 : Nationalités & Origines

## Objectif du jour
Dire d'où l'on vient et sa nationalité.

## Vocabulaire : Pays et Nationalités
| Pays (País) | Nationalité (Masculin / Féminin) |
| :--- | :--- |
| **O Brasil** | Brasileiro / Brasileira |
| **A França** | Francês / Francesa |
| **Os Estados Unidos** | Americano / Americana |
| **A Alemanha** | Alemão / Alemã |
| **Portugal** | Português / Portuguesa |

## Grammaire : Préposition DE + Article
Pour dire l'origine, on utilise **Ser + de** (Être de...).
La préposition **de** se contracte avec l'article du pays (o, a, os, as).

*   de + o = **do**
*   de + a = **da**
*   de + os = **dos**
*   de + as = **das**

### Exemples
*   Eu sou **do** Brasil. (Le Brésil)
*   Eu sou **da** França. (La France)
*   Eu sou **de** Paris. (Paris n'a pas d'article, généralement)
