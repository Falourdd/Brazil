# Semaine 1, Jour 5 : Verbe Estar (État Temporaire)

## Objectif du jour
Exprimer comment on se sent *maintenant* (état passager).

## Grammaire : Verbe ESTAR (Présent)
Contrairement à *Ser* (permanent), **Estar** est utilisé pour les états temporaires, les émotions, et la localisation.

| Portugais | Français |
| :--- | :--- |
| **Eu estou** | Je suis (actuellement) |
| **Você está** | Tu es / Vous êtes |
| **Ele / Ela está** | Il / Elle est |
| Nós estamos | Nous sommes |
| Eles / Elas estão | Ils / Elles sont |

*> Prononciation : En langage courant, "estou" se prononce souvent "tô" et "está" se prononce "tá".*

## Vocabulaire : États et Sentiments
*   **Bem** : Bien
*   **Mal** : Mal
*   **Cansado / Cansada** : Fatigué(e)
*   **Feliz** : Heureux/Heureuse
*   **Triste** : Triste
*   **Doente** : Malade
*   **Com fome** : Affamé (Avoir faim - littéralement "avec faim")

## Ser vs Estar
*   *Ela **é** feliz.* (Elle est une personne heureuse par nature.)
*   *Ela **está** feliz.* (Elle est heureuse en ce moment.)
