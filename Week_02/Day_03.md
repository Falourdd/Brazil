# Semaine 2, Jour 3 : La Famille

## Objectif du jour
Parler de sa famille proche.

## Vocabulaire : A Família
*   **Pai / Mãe** : Père / Mère
*   **Pais** : Parents
*   **Filho / Filha** : Fils / Fille
*   **Irmão / Irmã** : Frère / Sœur
*   **Avô / Avó** : Grand-père / Grand-mère (Attention à l'accent !)
    *   Avô (Son fermé "o")
    *   Avó (Son ouvert "ò")
*   **Marido / Mulher (ou Esposa)** : Mari / Femme

## Grammaire : Surnoms affectueux
Les Brésiliens utilisent souvent des diminutifs.
*   Mãe -> **Mãe, Mainha, Mamãe**
*   Pai -> **Pai, Painho, Papai**
