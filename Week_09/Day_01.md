# Semaine 9, Jour 1 : Le Corps Humain

## Objectif du jour
Nommer les parties du corps.

## Vocabulaire : O Corpo
*   **A Cabeça** : La tête
*   **O Braço** : Le bras
*   **A Perna** : La jambe
*   **A Mão** : La main
*   **O Pé** : Le pied
*   **O Olho** : L'oeil (Olhos = Yeux)
*   **O Cabelo** : Les cheveux
*   **A Barriga** : Le ventre

## Expression
*   **Estou com dor de...** : J'ai mal à...
*   *Estou com dor de cabeça.*

## Exercices
1.  J'ai mal au ventre. -> Estou com dor de ________.
2.  Elle a les yeux bleus. -> Ela tem ________ azuis.
