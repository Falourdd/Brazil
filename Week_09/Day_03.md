# Semaine 9, Jour 3 : Passé - Ser et Ir

## Grammaire : Le Grand Classique
Au passé (Pretérito Perfeito), le verbe **Ser** (Être) et le verbe **Ir** (Aller) sont IDENTIQUES.
Oui, c'est le contexte qui décide.

| Pronom | Conjugaison (Ser / Ir) |
| :--- | :--- |
| **Eu** | **Fui** |
| **Você / Ele** | **Foi** |
| **Nós** | **Fomos** |
| **Eles** | **Foram** |

## Exemples
1.  *Eu **fui** ao Brasil.* (Je suis allé - Verbe Ir)
2.  *O filme **foi** bom.* (Le film a été bon - Verbe Ser)
3.  *Nós **fomos** amigos.* (Nous avons été amis - Verbe Ser)
