# Semaine 4, Jour 5 : Verbe IR (Aller)

## Objectif du jour
Dire où l'on va et parler du futur proche.

## Grammaire : Verbe IR (Totalement irrégulier)
| Pronom | Conjugaison |
| :--- | :--- |
| **Eu** | **Vou** |
| **Você / Ele / Ela** | **Vai** |
| **Nós** | **Vamos** |
| **Eles / Elas** | **Vão** |

## Le Futur Proche (TrÈS IMPORTANT)
Au Brésil, on utilise rarement le futur simple. On utilise **Ir + Infinitif**.
*   *Eu **vou** falar.* (Je vais parler).
*   *Nós **vamos** comprar.* (Nous allons acheter).
*   *Você **vai** viajar?* (Tu vas voyager ?)

## Exercices
1.  Je vais à la plage. -> Eu ________ para a praia.
2.  Nous allons manger maintenant. -> Nós ________ comer agora.
3.  Ils vont dormir. -> Eles ________ dormir.
