# Semaine 4, Jour 4 : Verbe FAZER (Faire)

## Objectif du jour
Dire ce que l'on fait.

## Grammaire : Verbe FAZER (Irrégulier)
| Pronom | Conjugaison |
| :--- | :--- |
| **Eu** | **Faço** (Irrégulier!) |
| **Você / Ele / Ela** | **Faz** |
| **Nós** | **Fazemos** |
| **Eles / Elas** | **Fazem** |

## Expressions avec Fazer
*   **Fazer compras** : Faire les courses / du shopping.
*   **Fazer comida** : Cuisiner.
*   **Fazer calor/frio** : Faire chaud/froid (Météo).
    *   *Faz calor hoje.* (Il fait chaud aujourd'hui.)

## Pratique du jour (30% - Fazer)
1.  Je fais le gâteau. -> Eu ________ o bolo.
2.  Nous faisons. -> Nós ________.
3.  Il fait chaud. -> ________ calor.
