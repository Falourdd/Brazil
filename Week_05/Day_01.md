# Semaine 5, Jour 1 : Les Loisirs

## Objectif du jour
Parler de ce qu'on aime faire.

## Vocabulaire : Lazer (Loisir)
*   **A Praia** : La plage (Lieu sacré au Brésil)
*   **O Futebol** : Le football
*   **A Música** : La musique
*   **Viajar** : Voyager
*   **Ler** : Lire
*   **Dançar** : Danser
*   **Assistir TV** : Regarder la télé ("Assistir a" = Regarder un spectacle/film)

## Note Culturelle
Le week-end (Fim de semana) est très important. On demande souvent :
*   *O que você vai fazer no fim de semana?*
