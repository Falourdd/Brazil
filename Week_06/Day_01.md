# Semaine 6, Jour 1 : La Nourriture

## Objectif du jour
Identifier les bases de l'alimentation brésilienne.

## Vocabulaire : Comida
*   **O Arroz** : Le riz (Base de tout repas)
*   **O Feijão** : Le haricot (généralement noir ou marron)
*   **A Carne** : La viande (Boeuf)
*   **O Frango** : Le poulet
*   **O Peixe** : Le poisson
*   **A Salada** : La salade
*   **A Fruta** : Le fruit

## Boissons (Bebidas)
*   **A Água** : L'eau (Com gás / Sem gás)
*   **O Suco** : Le jus (Suco de laranja = jus d'orange)
*   **A Cerveja** : La bière ("Uma cerveja gelada" = une bière glacée)
*   **O Café** : Le café ("Cafezinho")
