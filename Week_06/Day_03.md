# Semaine 6, Jour 3 : Au Restaurant

## Objectif du jour
Commander un repas.

## Expression Clé : Queria...
Pour commander poliment, on utilise l'imparfait de "Querer" (Vouloir) : **Eu queria...** (Je voulais/voudrais).
*   *Eu queria um suco de laranja.*

## Vocabulaire du restaurant
*   **O Cardápio** : Le menu
*   **A Conta** : L'addition
*   **O Garçom** : Le serveur
*   **Por favor** : S'il vous plaît

## Dialogue type
*   Garçom: *Pois não?* (Oui? / Je peux vous aider ?)
*   Cliente: *Eu queria o prato do dia, por favor.*
*   Garçom: *E para beber?*
*   Cliente: *Uma água, por favor.*
*   ...
*   Cliente: *A conta, por favor!*
