# Semaine 8, Jour 4 : Décrire le Passé

## Objectif du jour
Donner des détails sur ses expériences.

## Adjectifs descriptifs
*   **Legal** : Cool / Super (Le mot le plus utile du Brésil !)
*   **Incrível** : Incroyable
*   **Chato** : Ennuyeux / Pénible
*   **Barato** : Bon marché
*   **Caro** : Cher
*   **Delicioso** : Délicieux

## Exemples
*   *A viagem foi incrível.* (Le voyage a été incroyable - "Foi" est le passé de Ser/Ir).
*   *O filme foi chato.*

## Pratique du jour (30% - Description Passé)
1.  Le dîner était délicieux. -> O jantar estava ________.
2.  C'est très cool ! -> É muito ________!
3.  Le voyage a été cher. -> A viagem foi ________.
