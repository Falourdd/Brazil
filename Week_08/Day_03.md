# Semaine 8, Jour 3 : Le Passé des verbes en -ER / -IR

## Grammaire : Conjugaison (Réguliers)
Les terminaisons sont identiques pour -ER et -IR au passé !

Verbes **Comer** et **Abrir**.

| Pronom | Terminaison (-ER/-IR) | Conjugaison |
| :--- | :--- | :--- |
| **Eu** | **-i** | Com**i** / Abr**i** |
| **Você / Ele** | **-eu / -iu** | Com**eu** / Abr**iu** |
| **Nós** | **-emos / -imos** | Com**emos** / Abr**imos** |
| **Eles** | **-eram / -iram** | Com**eram** / Abr**iram** |

## Exemples
*   *Eu **comi** uma feijoada.* (J'ai mangé...)
*   *Você **bebeu** caipirinha?* (Tu as bu...)
*   *Eles **saíram** cedo.* (Ils sont sortis...)
