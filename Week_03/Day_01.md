# Semaine 3, Jour 1 : La Maison

## Objectif du jour
Nommer les pièces principales de la maison.

## Vocabulaire : Pièces (Cômodos)
*   **A Casa** : La maison
*   **O Apartamento** : L'appartement
*   **A Sala** : Le salon (ou salle de séjour)
*   **A Cozinha** : La cuisine
*   **O Banheiro** : La salle de bain / toilettes
*   **O Quarto** : La chambre
*   **O Escritório** : Le bureau (pièce)

## Expression Utile
*   **Onde você mora?** (Où habitez-vous ?)
*   **Eu moro em...** (J'habite à/en...)

## Exercices
1.  Associez :
    *   Dormir -> (Cozinha / Quarto / Sala)
    *   Manger -> (Banheiro / Cozinha / Quarto)
    *   Regarder la TV -> (Sala / Banheiro / Escritório)
