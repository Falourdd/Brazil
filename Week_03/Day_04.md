# Semaine 3, Jour 4 : La Routine

## Objectif du jour
Raconter sa journée type.

## Vocabulaire : Verbes de routine (souvent en -AR)
*   **Acordar** : Se réveiller
*   **Levantar** : Se lever
*   **Tomar banho** : Prendre une douche (litt. "Prendre bain")
*   **Tomar café** : Prendre le petit-déjeuner
*   **Almoçar** : Déjeuner (Midi) - *Attention: Verbe en -AR (Eu almoço)*
*   **Jantar** : Dîner (Soir) - *Attention: Verbe en -AR (Eu janto)*
*   **Chegar** : Arriver

## Les moments
*   **De manhã** : Le matin
*   **À tarde** : L'après-midi
*   **À noite** : Le soir

## Pratique du jour (30% - Routine)

2.  Je dîne. -> Eu ________.
3.  Le matin. -> De ________.
