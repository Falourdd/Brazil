# Semaine 3, Jour 2 : Les Meubles

## Objectif du jour
Meubler vocabulairement votre maison.

## Vocabulaire : Mobília
*   **A Mesa** : La table
*   **A Cadeira** : La chaise
*   **O Sofá** : Le canapé
*   **A Cama** : Le lit
*   **A Geladeira** : Le frigo
*   **O Fogão** : La cuisinière
*   **A Televisão (TV)** : La télévision

## Prépositions de base
*   **Em cima de** : Sur
*   **Embaixo de** : Sous
*   **Dentro de** : Dans
*   **O livro está em cima da mesa.**

## Pratique du jour (30% - Meubles)
1.  Sous la table -> ________ da mesa.
2.  La chaise -> A ________.
3.  Le livre est sur le lit. -> O livro está em cima da ________.
