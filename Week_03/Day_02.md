# Semaine 3, Jour 2 : Les Meubles

## Objectif du jour
Meubler vocabulairement votre maison.

## Vocabulaire : Mobília
*   **A Mesa** : La table
*   **A Cadeira** : La chaise
*   **O Sofá** : Le canapé
*   **A Cama** : Le lit
*   **A Geladeira** : Le frigo
*   **O Fogão** : La cuisinière
*   **A Televisão (TV)** : La télévision

## Prépositions de base
*   **Em cima de** : Sur
*   **Embaixo de** : Sous
*   **Dentro de** : Dans
*   **O livro está em cima da mesa.**

## Exercices
1.  Où est le lait ? -> Na _______ (Frigo).
2.  Où je dors ? -> Na _______ (Lit).
